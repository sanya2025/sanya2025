## Selected Work

### [Multimodal Research & Teaching Assistant](https://github.com/sanya2025/multimodal-research-teaching-assistant)
Open-source multimodal retrieval, grounding, and evaluation system for research documents.  
Combines text, figure-caption, and visual retrieval with canonical evidence tracking, rank fusion, cross-encoder reranking, and grounded generation. Runs fully locally (Ollama + FAISS).

**Highlights:** Frozen evaluation benchmark, ablation results (Recall@5 0.605), Docker, CI, teaching modes, citation verification.

### [edututor-eval](https://github.com/sanya2025/edututor-eval)
Lightweight evaluation framework for AI tutoring responses.  
Measures correctness, pedagogical alignment, curriculum grounding, engagement, and safety — dimensions standard NLP metrics miss.

**Highlights:** Multi-strategy evaluation (rule-based, LLM-as-judge, learned classifier), rubric-driven, education-specific.

### [Grounded Multimodal Memory](https://github.com/sanya2025/grounded-multimodal-memory)
Research project on visual evidence, temporal retrieval, and efficient multimodal reasoning.  
Structured scene understanding, multimodal memory, and accuracy–latency–memory tradeoffs.
